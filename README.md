# ORBITAL LAB — Spacecraft Fire Simulator

Самостоятельная браузерная демо-версия учебной лаборатории. Никакие пакеты, сервер, аккаунт или API-ключи не требуются.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.

Если браузер ограничивает локальные файлы, откройте папку в терминале и выполните:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Возможности

- Разделы «Обзор», «Лаборатория», «Статистика», «Профиль» и «О модели».
- Переключение русского и английского языка, светлой и тёмной темы.
- Параметры давления, кислорода, начальной температуры, потока воздуха, длительности, гравитации, материала и пожаротушения.
- Четыре готовых сценария; парциальное давление кислорода рассчитывается как общее давление × доля кислорода.
- Детерминированная шаговая учебная модель с анимацией визуальной модели, живыми метриками и графиком.
- Запуск, пауза, продолжение и сброс без удаления истории.
- Сохранение запусков в `localStorage`, история, сравнение двух сценариев, экспорт JSON и CSV.
- Адаптивная раскладка, клавиатурный фокус и доступные подписи интерактивных элементов.

Все значения синтетические. Это образовательная демонстрация, а не CFD, инженерная модель, прогноз безопасности или инструкция по тушению.
